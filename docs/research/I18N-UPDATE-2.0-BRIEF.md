# Brief: update one language for ai-jail 2.0

The English catalogs changed for ai-jail 2.0 (filtered egress `--allow-host`, launch audit log, `--env-from-file`, a new Download page). Your job is to bring `src/i18n/locales/<locale>/` back to 100% with no STALE entries, in the same voice as the existing translation.

1. Read `docs/research/I18N-TRANSLATE-BRIEF.md` (rules, glossary, register) and `docs/i18n/glossary-<locale>.md`. Read `docs/research/UPDATE-2.0-BRIEF.md` for what the new features are, so the translation is accurate.
2. Run `node scripts/check-i18n.mjs <locale>`. It lists every STALE key (English changed) and every key falling back to English (new). `download.json` is entirely new. Some arrays changed length (for example `security.json` `switches.rows` grew, `compare.json` gained a `platforms` block and `table.rows` changed): rebuild those arrays to match English item for item, translating each.
3. Translate only what the check lists; leave everything else exactly as it is. New glossary terms (suggested; adapt to your language): filtered egress = "saída filtrada"/"salida filtrada"/"יציאה מסוננת"/"フィルタ付き外向き通信"/"필터링된 외부 연결"; allowed host = host permitido / host permitido / host מורשה / 許可ホスト / 허용된 호스트; audit log = log de auditoria / registro de auditoría / יומן ביקורת / 監査ログ / 감사 로그; proxy stays "proxy"; release notes = notas da release / notas de la versión / הערות גרסה / リリースノート / 릴리스 노트; checksum stays "checksum" in pt-br/es, "체크섬", "チェックサム", "checksum" in he. Record what you decide in the glossary file.
4. `images.json`: add translations for the new image `how-egress` (labels: Off, Filtered, Open, Proxy; api.anthropic.com is not a key) and for the changed `install-first-run` (its "Network" label is now "API host"; translate that one, keep the others as they were). Then run `node scripts/localize-image.mjs how-egress <locale>` and `node scripts/localize-image.mjs install-first-run <locale>` (about 40 s each), LOOK at both results next to the English originals (`src/assets/img/gen/<name>.webp`), retry at most twice if a label is wrong or cut, and delete the localized file if it still fails (English fallback is better than a wrong label).
5. Re-read your new strings once as a reader (no translation tells, no dashes as connectors, no "not X but Y", short headlines).
6. `node scripts/check-i18n.mjs --stamp <locale>` then `node scripts/check-i18n.mjs <locale>`: no errors, nothing falling back to English.
Touch only `src/i18n/locales/<locale>/`, `src/assets/img/gen/<locale>/` and `docs/i18n/glossary-<locale>.md`. Do not run `astro build`. Report under 100 words: check result, which of the two images passed, terms you were unsure about.
