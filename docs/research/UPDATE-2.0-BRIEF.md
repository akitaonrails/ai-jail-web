## What changed (all opt-in, every 1.x config keeps working)

1. **Filtered egress**: `--allow-host HOST` (repeatable) or `allow_hosts = [...]`. A third network mode between off and `--network`: the sandbox reaches exactly the listed hosts and their subdomains, over TCP through a built-in CONNECT proxy (about 400 lines, std only, no TLS termination, no CA). On Linux the sandbox keeps its private network namespace with no route out; a small in-sandbox bridge (started before Landlock and seccomp apply) forwards loopback TCP to the proxy over a bind-mounted Unix socket. On macOS the seatbelt profile allows outbound only to `localhost:<proxy-port>`. `http_proxy`/`https_proxy`/`all_proxy` are forced to the proxy inside. DNS resolves once, outside, and the checked answer is the one dialed (no DNS rebinding); private, loopback, link-local, CGNAT, multicast and cloud-metadata addresses are refused. Proxy-unaware programs that ignore `http_proxy` simply fail. No UDP. On Linux there is no working DNS inside the sandbox; on macOS the system resolver is not fenced (a low-bandwidth DNS channel remains, the same gap Anthropic's sandbox-runtime documents). Cannot combine with `--network` or `--browser` (launch error). A project `.ai-jail` may only shrink the list, never grow it. Works with `--lockdown` (tighter than lockdown's "no network"; on kernels 6.7+ lockdown's Landlock V4 rules allow ConnectTcp to the bridge port only). Caveat: an allowed host is trusted wholesale (allowing github.com permits pushing to any repo). The proxy sees CONNECT metadata (host, port, timing), not content. Launch warnings for known agents now know this mode: no network warning when the agent's API host is in the list, and a warning naming the missing host otherwise. Known hosts: claude → api.anthropic.com, codex → api.openai.com, gemini → generativelanguage.googleapis.com.
2. **Launch audit log**: `--audit-log` / `audit_log = true`. Off by default. Appends one JSONL record per launch (timestamp, command, effective capabilities, config sources, exit code, duration) to `~/.local/share/ai-jail/history.jsonl` (dir 0700, file 0600, symlinks refused, outside every mount so the sandbox never sees it). With filtered egress on, every CONNECT allow/deny verdict is recorded too. A project `.ai-jail` can disable but never enable it.
3. **`--env-from-file PATH`** (repeatable; `env_from_file` in the global config only). Reads strict `KEY=VALUE` lines (`#` comments and blank lines skipped, no `export`, no quote stripping) from a file that must be user-owned, a regular file (not a symlink), mode 0600 or stricter, and outside the project; any violation fails the launch. Applies like `--env`; `--env` wins on conflicts. Never persisted; project `.ai-jail` cannot set it. The pattern: secrets live in the host environment or a 0600 file, never in any `.ai-jail`.
4. `--allow-tcp-port` still fails closed (UDP cannot be constrained); its error now points at `--allow-host`.
5. `docs/openshell-comparison.md` compares ai-jail with NVIDIA OpenShell (an agent runtime platform: daemon, containers or MicroVMs, OPA policy, CONNECT proxy with L7 inspection, credential brokering, OCSF audit logs). It is honest in both directions; use it only where the Compare page brief says.

## Consequences for the site

- Everywhere the site says the network is "all or nothing" or that ai-jail has "no per-domain filter, on purpose", that is now false. Rewrite with the three modes: off (default), filtered (`--allow-host`), open (`--network`).
- The "Why no per-domain allowlist?" FAQ on Compare must be replaced: the old objection (a filter inside the sandbox that the agent can decline) is answered by the design: the fence is the network namespace itself (Linux) or a seatbelt endpoint rule (macOS), so a process that ignores the proxy reaches nothing.
- The version and counts come from `facts.json`.
- Diagram prompts: new diagrams go in `scripts/prompts/<page>-<topic>.txt`, generated with `node scripts/gen-image.mjs <name>`, then LOOKED at. Add every translatable label of a new diagram to `src/i18n/locales/en/images.json` under the image name (`{"Label": "Label"}`), and list the labels in your report. Do not regenerate existing diagrams unless they are now wrong (the Landlock diagrams are not wrong).
