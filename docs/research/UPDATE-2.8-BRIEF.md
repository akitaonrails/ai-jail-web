## What changed

1. **A bare launch of a known agent reaches its own API by default (2.8.0).** With no network flag, no explicit `--allow-host` list, not lockdown, not a browser launch, ai-jail adds filtered egress to that agent's one documented API host: `claude` → `api.anthropic.com`, `codex` → `api.openai.com`, `gemini` → `generativelanguage.googleapis.com`, `grok` → `api.x.ai`. Only that host, never telemetry; deny-by-default still holds. This applies on macOS too (unlike the registry default, which is Linux only). An explicit `--allow-host` list is used verbatim instead (so a list that omits the API host blocks it; add it yourself). `--no-network` keeps everything offline. Gated on the same netns probe on Linux. Consequence: `ai-jail claude` works out of the box, logged in (2.6) and able to reach its API (2.8). The "one thing to open" story from 2.6 is now "nothing to open for a known agent".
2. **`--github` forwards the active github.com token (2.7.0).** `gh auth login` stores tokens in the system keyring; `--github` now runs `gh auth token` on the host (no shell, 5 s timeout) and forwards it as `GH_TOKEN` for that launch, through the in-memory file, never argv or disk; dry-run never fetches it; an explicit `GH_TOKEN`/`GITHUB_TOKEN` via `--env` skips the lookup; only github.com and the active account; still opt-in, monotonic, off under lockdown. It also mounts the effective gh config dir read-only (`GH_CONFIG_DIR`, `$XDG_CONFIG_HOME/gh`, or `~/.config/gh`).
3. **New recognized agents for agent state:** `kiro-cli` (`~/.kiro` plus `~/.local/share/kiro-cli` on Linux, `~/Library/Application Support/kiro-cli` on macOS; listed in the presets) and `prime-agent` (`~/.prime/agent` only, never the whole `~/.prime`).
4. **macOS fixes (2.8.0):** the seatbelt profile preserves Claude Code's Keychain login and allows the Codex app-server control socket, so both launch logged in on macOS. **Terminal:** cursor-position requests from a launcher are answered from the virtual terminal, so launchers no longer stall.
5. **Env values (2.6.2 restated):** on Linux `--env`/`--env-from-file` values travel to bwrap through an in-memory file and never appear on the launcher's argv; a literal `--env NAME=VALUE` is still visible on ai-jail's own command line, so prefer `--env NAME` or `--env-from-file` for secrets.
6. Fixes not worth site text: private-home command exemption preserves symlink chains (bun/prime launchers), proxy accept retry, Nix test skip.
