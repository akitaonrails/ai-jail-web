Run your coding agent in a jail. Keep your home out of it.

ai-jail starts Claude Code, Codex or any other agent inside a Linux or macOS sandbox. The project is writable. Your SSH keys, cloud credentials, shell secrets and the rest of your home are not there.

$ ai-jail claude

Where the wall is

Agents that ship a sandbox put it around the commands the model runs. ai-jail puts the agent itself inside.
